📋 *ORDERS TAB*

*Upload daily orders (Excel/CSV):*
1️⃣ Tap the upload zone → select your Excel file
2️⃣ Tap *"Preview"* to review before saving
3️⃣ Tap *"Confirm & Save All"*
   → Drivers get notified automatically 🔔

*Filters:* All / Done / Pending (click the count)

*Excel file format required:*
   Columns: Customer ID, Shop Name, Driver,
   Items, Qty, Date, DC Number

---

✅ *APPROVE TAB (New Customers)*

When a new shop appears in orders for the first time:
1️⃣ Go to *Approve* tab
2️⃣ Review the new customer details
3️⃣ Assign a driver
4️⃣ Tap *"Approve"* → shop is added to the system

---

📊 *SUMMARY TAB*

• Select a date → see full day summary
• All drivers, their shops, items & quantities
• Useful for morning dispatch verification

---

🚚 *DELIVERY TAB*

• Shows which shops are delivered / pending
• Filter by: All / Done / Pending
• Tap count buttons to filter
• Select different dates to see history

---

🗺 *ROUTES TAB*

• Shows each driver's route for the day
• Displays: shops delivered, total shops,
  distance, estimated time
• [No GPS] shown for shops missing coordinates
• Filter: All / Done / Pending

---

🏪 *CUSTOMERS TAB*

*Add new shop:*
1️⃣ Tap *"+ Add Customer"*
2️⃣ Fill in: Name, ID, Address, Area, Driver, Mobile
3️⃣ Tap *"Save"* → assigned driver gets notified 🔔

*Edit shop:*
• Tap the shop → edit details → Save
• Changing driver → new driver gets notified 🔔

*Bulk move shops:*
• Use *"Move Customers"* section
• Select From driver → To driver → Move
• Target driver gets notified automatically 🔔

*Delete shop:*
• Tap shop → tap Delete (cannot be undone)

---

📦 *PRODUCTS TAB*

• View all bakery products
• Add / Edit / Delete products
• Upload products via Excel in bulk
• Fields: Product ID, Name, Category, Price, Unit

---

🚗 *DRIVERS TAB*

*Add driver:*
1️⃣ Tap *"+ Add Driver"*
2️⃣ Fill: Name, Password, Mobile, Color
3️⃣ For live tracking:
   - Paste Ajjas share link in *"Live Tracking Link"*
   - Set *"Live Tracking"* to Enabled
4️⃣ Save

*Edit driver:*
• Tap driver → Edit → change details → Save
• To change password → fill new password field

*Delete driver:*
• Only when driver is no longer active

---

👥 *USERS TAB (Super Admin only)*

• Add / Edit / Delete staff accounts
• Roles: super_admin / admin / assistant / chef / packer
• Each role can have specific tab access
• Active / Inactive toggle

---

🗑 *DATA MAINTENANCE (Super Admin only)*

Located in the *GPS tab* (scroll to bottom)

• Tap *"Delete Data Older Than 7 Days"*
• Deletes: orders, deliveries, routes, notifications
• Shops & products are NOT deleted
• Confirm the popup → data is permanently deleted

---

⚠️ *IMPORTANT NOTES*

• Orders tab auto-skips duplicate DC numbers
• New customers go to *Approve tab* first
  before appearing in driver routes
• Always verify preview before confirming upload
• Super Admin can access everything
• Admin tab access is set by Super Admin
