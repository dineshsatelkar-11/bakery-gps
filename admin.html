How to get these:
1. Go to api-console.zoho.in
2. Create a Self Client → copy Client ID & Secret
3. Generate Code with scope: ZohoBooks.invoices.CREATE,ZohoBooks.contacts.READ,ZohoBooks.settings.READ
4. Exchange code for refresh token using Postman or curl
5. Org ID: Zoho Books → Settings → Organization Profile
